# src-tauri — meeting-app Tauri binary

The `app-main` crate. Wires every Phase 1 crate into a running Tauri desktop app.

## Generating TypeScript IPC bindings

The `ui/src/ipc/bindings.ts` file is generated by tauri-specta and must be
regenerated after any command or event surface change in `ipc-bridge`.

```sh
# From the workspace root:
cargo run -p meeting-app --bin generate-bindings

# Or using the cargo alias:
cargo gen-bindings
```

The output path is always `<workspace-root>/ui/src/ipc/bindings.ts`.

## Development

```sh
# Build the binary (no GUI — works on WSL/CI):
cargo build -p meeting-app

# Lint:
cargo clippy -p meeting-app -- -D warnings

# Format check:
cargo fmt --check
```

## Tray icon art

Icons under `icons/` are placeholder solid-colour PNGs (Phase 1).
Final art is Phase 7.
